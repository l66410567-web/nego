# 무료 사전등록 → 문자 알림 연동 설치 안내

등록 버튼을 누르면 **사장님 휴대폰으로 즉시 문자**가 오고, 구글 시트에 명단이 쌓입니다.
아래 순서대로 한 번만 하시면 됩니다. (약 20분)

---

## 0단계 — 준비물

| 필요한 것 | 어디서 |
|---|---|
| 알리고 계정 + API Key | https://smartsms.aligo.in → 가입 → 문자 충전 |
| **발신번호 사전등록** | 알리고에서 `1533-9657` 사전등록 (필수, 미등록 시 발송 불가) |
| 구글 계정 | 명단 저장용 (**2단계 인증 꼭 켜주세요**) |

---

## 1단계 — 구글 시트 만들기

1. https://sheets.google.com 에서 새 시트 생성
2. 이름: `빛고을장례119 사전등록 명단`
3. 주소창에서 **시트 ID** 복사
   `docs.google.com/spreadsheets/d/` **`이 부분이 시트ID`** `/edit`

> 이 시트에는 고객 개인정보가 쌓입니다. **다른 사람과 공유하지 마세요.**

---

## 2단계 — Apps Script 붙여넣기

1. 만든 시트에서 **확장 프로그램 → Apps Script**
2. 기본 코드를 모두 지우고, `prereg.gs` 파일 내용을 통째로 붙여넣기
3. 저장(💾)

---

## 3단계 — 비밀값 설정 (⭐ 가장 중요)

Apps Script 화면 왼쪽 **⚙️ 프로젝트 설정 → 스크립트 속성 → 속성 추가**

| 속성 이름 | 값 |
|---|---|
| `ALIGO_KEY` | 알리고 API Key |
| `ALIGO_USER_ID` | 알리고 아이디 |
| `ALIGO_SENDER` | `1533-9657` (사전등록한 발신번호) |
| `NOTIFY_TO` | 알림 받을 휴대폰 (예: `010-1234-5678`) |
| `FORM_TOKEN` | 아무 임의 문자열 (예: `bitgoeul-2026-a7x9k2`) |
| `SHEET_ID` | 1단계에서 복사한 시트 ID |

> **API 키는 여기에만 저장됩니다.** 홈페이지 소스에는 절대 들어가지 않습니다.

---

## 4단계 — 문자 발송 테스트

1. 상단 함수 목록에서 `테스트발송` 선택 → **실행**
2. 첫 실행 시 권한 승인 창 → 허용
3. 사장님 휴대폰으로 테스트 문자가 오면 성공
4. 실행 로그에 `success` 또는 `결과코드 1` 이 보이면 정상

---

## 5단계 — 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 유형: **웹 앱**
3. 설정:
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** ← 홈페이지에서 호출해야 하므로 필수
4. 배포 → **웹 앱 URL 복사** (`https://script.google.com/macros/s/.../exec`)

---

## 6단계 — 홈페이지에 연결

`script.js` 파일 상단의 두 줄을 채웁니다.

```javascript
var PREREG_ENDPOINT = '여기에 5단계에서 복사한 웹앱 URL';
var PREREG_TOKEN    = '여기에 3단계의 FORM_TOKEN 과 똑같은 값';
```

저장 후 배포하면 끝입니다. **이 두 줄을 채워달라고 말씀만 주시면 제가 넣어드립니다.**

---

## 7단계 — 실제 확인

1. 홈페이지에서 **무료 사전등록하기** → 본인 정보로 제출
2. 사장님 휴대폰에 문자 도착 확인
3. 구글 시트에 행이 추가되었는지 확인

---

## ⚠️ 반드시 함께 해야 할 것

### 개인정보처리방침 수정
현재 방침(`privacy.html`)은 **상담 신청 기준**이라 사전등록과 안 맞는 부분이 있습니다.

| 조항 | 현재 | 수정 필요 |
|---|---|---|
| 제1조 수집항목 | 성함, 연락처, 상담시간, 상담내용 | **거주지역 추가** |
| 제3조 보유기간 | 상담 완료 후 **최대 1년** | 사전등록은 장기 보관이 목적 → **"사전등록: 등록일로부터 5년 또는 삭제 요청 시까지"** 별도 명시 |
| 제5조 위탁 | 일반 조항만 있음 | **㈜알리고(문자 발송), Google LLC(데이터 보관)** 명시 |

> 폼의 동의 안내 문구에는 이미 **수집항목·목적·보유기간(5년)·거부권**을 표시해 두었습니다.
> 방침 본문도 같은 내용으로 맞춰야 일치합니다. 말씀 주시면 개정안을 작성해 드립니다.

### 보안 수칙
- 구글 계정 **2단계 인증** 필수
- 시트를 다른 사람과 공유하지 않기
- 알리고 잔액 알림 설정 (문자 폭탄 시 조기 인지)
- 고객이 삭제를 요청하면 **시트에서 해당 행 삭제**

## 문제가 생기면

| 증상 | 원인 |
|---|---|
| 문자가 안 옴 | 발신번호 사전등록 미완료 / 잔액 부족 |
| 시트에 안 쌓임 | `SHEET_ID` 오타 |
| 아무 반응 없음 | 5단계 액세스 권한이 "모든 사용자"가 아님 |
| 콘솔에 unauthorized | `FORM_TOKEN` 양쪽 값 불일치 |
