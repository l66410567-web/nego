# 온라인 추모관 → 구글 시트 저장 설치 안내

조문객이 올린 **헌화와 조문글이 구글 시트에 쌓이고**, 다른 조문객에게도 보이게 됩니다.
장례마다 페이지 파일을 새로 만들 필요가 없습니다. **시트에 한 줄 추가 → 링크 하나**가 생깁니다.

```
memorial.html?id=k7m2qx9p   ← 장례 A
memorial.html?id=t4hn8w2c   ← 장례 B
```

처음 한 번만 설치하시면 됩니다. (약 15분)

---

## 1단계 — 추모관 전용 구글 시트 만들기

1. https://sheets.google.com 에서 새 시트 생성
2. 이름: `빛고을장례119 온라인 추모관`

> ⚠️ **사전등록 명단 시트와 따로 만드세요.** 섞어 두면 관리와 삭제가 어려워집니다.
> 이 시트에는 고인·유족 정보와 계좌가 담깁니다. **다른 사람과 공유하지 마세요.**

---

## 2단계 — Apps Script 붙여넣기

1. 만든 시트에서 **확장 프로그램 → Apps Script**
2. 기본 코드를 모두 지우고 `memorial.gs` 내용을 통째로 붙여넣기
3. 저장(💾)
4. 위쪽 함수 목록에서 **`처음설정`** 선택 → **실행** → 권한 승인 창에서 허용
5. 시트로 돌아가 새로고침하면 위쪽 메뉴에 **[추모관]**이 생기고, 탭 3개(추모관·헌화·조문글)가 만들어집니다.

---

## 3단계 — 웹앱으로 배포

1. Apps Script 오른쪽 위 **배포 → 새 배포**
2. 유형: **웹 앱**
3. 실행 사용자: **나** / 액세스 권한: **모든 사용자**
4. 배포 → **웹 앱 URL 복사** (`https://script.google.com/macros/s/.../exec`)

---

## 4단계 — 홈페이지에 연결

`memorial.js` 맨 위 한 줄에 3단계 주소를 넣습니다.

```javascript
var MEMORIAL_API = '여기에 웹앱 URL';
```

**주소만 알려주시면 제가 넣어 드립니다.**

---

## 장례가 생길 때마다 (담당자 업무)

| 순서 | 할 일 |
|---|---|
| 1 | 시트 메뉴 **[추모관 → 새 추모관 만들기]** → 고인 성함 입력 → **링크가 나옵니다** |
| 2 | 만들어진 줄에 일정·인사말·장지 등을 채웁니다 (빈칸은 화면에서 자동으로 숨겨짐) |
| 3 | 사진: 구글 드라이브에 올리고 **공유 → 링크가 있는 모든 사용자** → 공유 링크를 `영정사진`, `사진1~9` 칸에 붙여넣기 |
| 4 | 계좌는 유족이 원할 때만 `계좌공개`를 **Y** |
| 5 | 유족께 화면 확인을 받은 뒤 **`공개`를 Y** 로 바꾸면 열립니다 |
| 6 | 링크를 부고 문자에 넣어 보냅니다 |

### 운영 중
- **부적절한 헌화·글**: 헌화/조문글 탭에서 그 줄의 `숨김` 칸에 **Y** → 20초 안에 내려갑니다
- **유가족에게만 전한 글**: 조문글 탭에서 `유가족에게만`이 Y인 글을 모아 유족께 전달합니다 (홈페이지에는 절대 나오지 않습니다)
- **장례 후 닫기**: `공개`를 **N** → "유가족의 뜻에 따라 닫혔습니다" 화면으로 바뀝니다
- **이름 가림**: 기본값 Y → 홍길동이 **홍○○** 로 보입니다. 유족이 원하면 N

### 사진 칸 규칙
| 사진 칸 | 화면 위치 |
|---|---|
| 사진1 | Ⅰ 젊은 날 (큰 사진) |
| 사진2~4 | Ⅱ 가족과 함께 |
| 사진5~8 | Ⅲ 웃음 (어두운 벽) |
| 사진9 | Ⅳ 마지막 인사 (액자 사진) |

사진이 없는 장(章)은 자동으로 감춰집니다. 사진이 하나도 없으면 사진전 전체가 감춰집니다.

> 📌 **첫 장례 전에 사진 1장으로 꼭 시험하세요.** 드라이브 공유 링크를 이미지로 바꾸는 방식은 구글 정책에 따라 달라질 수 있습니다.
> 사진이 안 뜨면 "사진을 불러오지 못했습니다"가 표시됩니다. 그때는 말씀 주세요.

## ⚠️ 반드시 함께 정할 것

| 항목 | 내용 |
|---|---|
| **보관 기간** | 추모관을 닫은 뒤 헌화·조문글을 언제 지울지 정하세요 (예: 닫은 날로부터 1년). 정해지면 개인정보처리방침에 넣어야 합니다 |
| **개인정보처리방침** | 조문객의 **성함·조문글**을 새로 받게 되므로 `privacy.html`에 수집항목·목적·보유기간 추가가 필요합니다 |
| **유족 동의** | 사진·계좌·인사말 공개는 유족의 동의를 받은 것만 올리세요 |
| **링크 관리** | 코드는 추측하기 어렵게 만들어지지만, 링크를 받은 사람은 누구나 볼 수 있습니다. 검색엔진에는 노출되지 않게 설정해 두었습니다 |

## 문제가 생기면

| 증상 | 원인 |
|---|---|
| "찾으시는 추모관이 없습니다" | 링크의 코드 오타, 또는 시트의 `코드` 칸 변경 |
| "유가족의 뜻에 따라 닫혔습니다" | `공개`가 Y가 아님 |
| "불러오지 못했습니다" | 3단계 액세스 권한이 "모든 사용자"가 아님 / `MEMORIAL_API` 주소 오타 |
| 시트를 고쳤는데 화면이 그대로 | 20초 저장(캐시) 후 바뀝니다. 새로고침 |
| 코드를 고친 뒤 반영 안 됨 | Apps Script는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다 |
